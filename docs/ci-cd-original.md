# DevOps CI/CD Project – Flask Application

## Project Overview
This project demonstrates a simple DevOps pipeline for deploying a Flask web application using Docker, Kubernetes, and GitHub Actions.

The goal is to simulate a real-world DevOps workflow including containerization, orchestration, and CI automation.

## Technologies Used
- Python (Flask)
- Docker
- Kubernetes (Minikube)
- GitHub Actions
- Git

## Project Architecture

Developer pushes code to GitHub
        ↓
GitHub Actions CI Pipeline runs
        ↓
Docker Image built
        ↓
Kubernetes Deployment
        ↓
Application accessible via Kubernetes service
